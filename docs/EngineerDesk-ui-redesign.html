Engineer Desk · UI 设计稿

iOS 质感重设计 · 基于 V2.0 全部功能 · 2026-10-24

0. 一句话定位

把现在的"桌面黄色便签"升级成一张安静、精致、随手可靠的 iOS 风格工作面：功能一个不少，视觉噪音减一半。三个关键词——留白、层级、材质。

  • 清晰（Clarity）：内容永远是主角，工具条与状态条退到 8% 透明度的灰阶里。
  • 克制（Deference）：只保留一种强调色（暖橙），其余信息用灰阶分五档轻重。
  • 深度（Depth）：用"卡片浮在桌面上"的柔和投影 + 0.5px 发丝线表达层级，不用粗边框。

与现状的差异

  • 标题栏：日期从裸文本改为日期胶囊（等宽数字，带星期），一眼可扫；返回/前进箭头加大点击热区。
  • 格式栏：按钮从"方框线框"改为无边框悬停显灰底，激活态唯一使用橙色实底——整条工具栏视觉重量约等于零。
  • 分割线：从 24 个红字符改为居中标签式分隔（细线 + DIVIDER 微标），既美观又保持归档语义。
  • 底部条：Todo 统计收进一个胶囊；项目胶囊右对齐、完成度用色相编码（绿=全部完成，橙=停滞）。

分区设计

  • 两栏都是圆角浅色面板（12px 圆角），左暖右冷 2 度色温差，暗示"正式 / 随手"。

  • 草稿区角落固定微标注「可搜 · 不归档」，防止误把草稿当正文归档。
  • 中间拖拽手柄用 4px 留白 + 悬停出现 2px 橙色圆点提示，平时不可见。

弹窗设计

  • 头部卡片化：图标放进 34px 圆角方块，「×天没碰」变成橙色小胶囊（≥7 天才出现），信息密度不变、焦虑感减半。
  • 进度条：4px 高、绿色渐变填充，配右上「最近日期」——比裸数字更有推进感。
  • 三态图标：从字符 ☐◐☑ 升级为 20px 圆角方块状态件（✓ 绿 / ◐ 橙 / 空灰），点击循环不变。
  • 选中子项：淡蓝底色块标记，「记一句进度」的目标一目了然。
  • 底部操作：主操作「记一句进度」橙色实底，其余灰底；项目删除收进「⋯」菜单，防误触。
  • Esc / 点外部关闭行为不变；弹窗出现动画 160ms 上浮 + 淡入（iOS sheet 手感）。

5. 主题

应用固定使用本稿定义的浅色主题，不跟随操作系统切换深色外观；便签仍可使用设置中提供的自定义背景色。

7. 落地路线（每步独立可交付）

阶段内容验收
UI-a 令牌化把颜色/圆角/字号/间距收敛为 QSS token 表，替换现有散落的内联样式界面无 #888 类随机灰，改一处全局生效
UI-b 窗口层暖纸白背景、18px 圆角、双层投影、发丝线替换所有边框视觉对比现状：噪音明显减少
UI-c 工具条格式栏/标题栏/底栏按本稿重构，日期胶囊、分割线标签式工具栏悬停/激活态符合规格
UI-d 弹窗项目弹窗按第 4 节重构 + 出现动画160ms 上浮淡入；信息层级与本稿一致
UI-e 主题固定浅色令牌，菜单与确认框使用统一样式不受系统深色模式影响

建议顺序：先 UI-a（纯重构、零视觉变化）再逐层上皮肤，任何一步不满意可单独回退。
