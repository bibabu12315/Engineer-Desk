Engineer Desk V2.0 设计稿

分区草稿（手动开关） × 项目胶囊弹窗 · 按天记录为根基不变 · 2026-10-24

1. 设计原则（讨论中已确认的共识）

  • 按天记录是产品根基：翻日期、日历、周报/阶段回顾场景不受影响。
  • 单窗口原则：不做多便签实例，避免桌面杂乱。
  • 轻量红线：记一条进度 ≤ 3 秒（弹一行输入框，回车即存）；不做重型项目管理视图。
  • 草稿必须可回顾：草稿内容自动沉淀、全文可搜——解决实体草稿纸"随手扔、找不着"的痛点。
  • 格式按钮化：工具栏按钮（Word 式），不使用 Markdown 语法，零记忆负担。
  • 白板只借灵感：借鉴"自由、随手"的触感，不做无限画布（PySide6 做飞书级白板性价比极低，已确认放弃；外链也不做）。

竞品依据：Things 3「项目即文档」（Cultured Code，两度 Apple Design Award）；Tot 七固定页防膨胀；Benchpad「scratchpad 是工作面不是档案馆」；PinSlip/StickUp! 便签 + 轻任务一体化。

弹窗交互规格

  • 子项三态：☑ 完成 / ◐ 进行中 / ☐ 未开始，点击图标循环切换。
  • 子项备注：行尾 ✎ 点开行内输入框，备注以小字灰显在子项下方，自动带日期。
  • 项目备注：大项目级自由文本（目标、资料、阶段总结），默认折叠，展开后可多行编辑。
  • 记一句进度：只弹一行输入框，回车即存——更新选中子项的"上次做到"并刷新活跃时间。
  • × 天没碰：按项目最近活跃时间计算，≥7 天变橙色，仅提示不打断。
  • 关闭：Esc 或点击弹窗外部；弹窗内所有修改即时落库。

3.2 胶囊行为

  • 胶囊显示 图标 + 项目名 + 完成数/总数；点按弹出弹窗，再次点按或 Esc 收起。
  • 胶囊按最近活跃度排序（最常推进的排前面）；数量超 6 个时胶囊条横向滚动，不设硬上限。
  • + 项目 胶囊：弹一行输入框（项目名 + 可选 emoji 图标），回车创建。
  • 项目不出现在日期导航和日历里，与按天记录完全隔离。

4. 归档流程（分割线块 → 项目）

当日便签写完一段→ 工具栏 ⎺ 插入分割线划块→ 块上右键→ 「归档到项目 ▾」选项目/子项→ 内容追加到该项目备注区（自动带日期）
  • 归档是复制而非移动：原文保留在当日便签里（保证按天回顾完整），项目里多一条带日期的记录。
  • 归档目标可选项目级（进项目备注）或子项级（进子项备注）。
  • 不归档的内容不做任何处理，靠全文搜索找回（已有能力）。

按钮行为存储方式
B / I / S / U选区加粗 / 斜体 / 删除线 / 下划线，再次点按取消正文从纯文本升级为富文本（QTextEdit HTML）；旧纯文本数据原样兼容显示

☑ 待办当前行变为可勾选待办行，点击行首复选框切换完成（删除线样式）
⎺ 分割线光标处插入分割线，划出一个可归档的块HTML 中 <hr> + 块边界标记
⬌ 分区切换当日单栏 / 左右分割模式按天记录 split_mode 字段

编辑器从 QPlainTextEdit 迁移到 QTextEdit：粘贴仍强制去格式（保留现有 insertFromMimeData 行为，粘贴外来内容一律变纯文本）。

6. 数据模型变更（SQLite，向后兼容迁移）

表 / 字段变更说明
notes.content改存 HTML旧纯文本视为合法 HTML 子集，无需迁移
notes.draft_content新增列右侧自由草稿区内容（HTML）
notes.split_mode新增列0=单栏 1=左右分割
projects新增表id, name, icon, note, sort_active_at, created_at
project_items新增表id, project_id, title, status(0/1/2), note, last_progress, updated_at

启动时执行增量迁移（ALTER TABLE / CREATE TABLE IF NOT EXISTS），不清库、不动既有数据；家里/公司两台机器各自本地迁移。
