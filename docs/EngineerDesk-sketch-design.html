01

三问速答

打包成 exe 发给别人，能用吗？

能，零配置。整个功能 = 一组静态 HTML/JS 文件 + 系统浏览器。PyInstaller 把 resources/sketch/ 随 exe 分发，点「✏️」用系统默认浏览器打开本地文件。对方只需 Windows 自带 Edge，无 Node、无网络、无安装。

exe 体积 +1~2 MB；不引入 QWebEngineView（那会 +100 MB）。

你体验的那个界面，好加吗？

好加，这正是官方设计的集成方式。Excalidraw 本体是 React 组件：Vite 建一个约百行的壳页面内嵌它，构建一次出纯静态文件。之后唯一长期维护的代码是波形面板——通过 excalidrawAPI.updateScene() 把参数变成画布原生元素。

手绘风格、导出、undo、快捷键全部白拿，零开发。

03

生成规则：参数 → 画布元素

自研生成器（决策依据见 §4）。方波 = 一条折线 line 元素；标注虚线 = 红色 dashed line；标签 = text 元素。全部通过一次 updateScene({elements:[...旧元素, ...新元素]}) 注入，Excalidraw 自带 undo。

参数默认换算规则
模板互补+死区决定通道结构与相位关系
周期数 N5基准格宽 20px，高电平宽 = D × 周期宽
占空比 D40%取整到 1px，保证边沿垂直
死区（格）0.5互补路下降沿延迟 dt、上升沿提前 dt
通道名CHA2, CHB1text 元素，16px，左对齐
标注线T1-T4每个死区边沿一条红色贯穿虚线，从左到右自动编号
插入位置视口中心取 getViewportCoords() 中心；与现有元素包围盒重叠则向下偏移 260px 重找
模板通道典型用途
单路 PWM1 路方波单管驱动说明
互补 PWM + 死区2 路互补 + 死区虚线同步 Buck/Boost、半桥（主场景）
三角波 · 向上计数锯齿波（上升-垂直回落）定时器 counter、斜坡补偿
三角波 · 中央对齐三角波（升-降对称）HRTIM/中心对齐 PWM 载波、与 CMP 比较生成 PWM
三角波 · 向下计数锯齿波（垂直上升-下降）向下计数定时器示意
三角波三种计数模式（对照芯片手册定时器 counter）： 
// 一路方波 = 1 条 line（折线顶点序列）
{
  type: "line", strokeColor: "#5B7FD6",
  strokeWidth: 2, strokeStyle: "solid",
  points: [[x0,y0],[x1,y0],[x1,y1], …]
}
// 死区标注虚线（可单条拖动）
{ type: "line", strokeColor: "#E24B4A",
  strokeStyle: "dashed", strokeWidth: 1,
  points: [[x, top],[x, bottom]] }
// 标签
{ type: "text", text: "T1", fontSize: 12,
  strokeColor: "#E24B4A" }
为什么选元素注入而不是贴图：SVG 截图贴进画布是死图，虚线无法对齐边沿；注入的元素与你手画的同构——这正是你「波形 + 红虚线分析」工作流的核心。
04

自研 vs 集成 WaveDrom

推荐 自研生成器（约 200 行 JS）

输出 = Excalidraw 原生元素，虚线可拖、全画布统一 undo；可定制电力电子专属模板（互补/移相/死区）；无外部依赖。

逻辑极小：参数 → 折线顶点数组，本质是几何换算。

备选 集成 WaveDrom（MIT，3.5k★）

输出 = SVG 图片，贴进画布是死图，红虚线无法对齐边沿；对任意位置标注支持弱（仅 edge 箭头/tick）；电力电子模板需自己包一层。

仅在将来需要「纯渲染不编辑」的 datasheet 级导出时再引入。

结论：自己写。决定性理由是输出格式必须与 Excalidraw 元素模型同构，WaveDrom 在这一环帮不上忙，反而多一层转换。

实现交接摘要

工程结构（一次性搭建）

sketch-app/            # Vite + React，构建一次出静态文件
├── src/main.tsx       # 挂 Excalidraw 组件
├── src/WavePanel.tsx  # 波形面板（本项目唯一业务代码）
├── src/wavegen.ts     # 参数→元素换算（纯函数，可单测）
└── dist/ → 拷入 resources/sketch/

仅依赖的 3 个稳定 API

api.updateScene({ elements })
api.getSceneElements()
api.getViewportCoords()

样式：面板与 island 用原生同款投影/圆角；品牌色对齐主工具——强调橙 #FF9F0A、标注红 #E24B4A、波形蓝 #5B7FD6。
