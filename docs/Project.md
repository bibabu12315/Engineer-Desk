
# Engineer Desk

## 项目简介

Engineer Desk 是一款专为软件工程师、嵌入式工程师和硬件工程师设计的本地桌面工作台。

它不是传统意义上的便签软件，而是一款用于管理每日工作、记录开发过程、积累个人技术知识的轻量级桌面工具。

软件坚持以下原则：

* 极简
* 快速启动
* 完全离线
* 所有数据仅保存在本地
* 无需账号
* 无需联网
* 无广告
* 长期可维护

项目定位不是 Office，不是 Notion，不是 OneNote，也不是 Todo 软件，而是每天开机都会陪伴工程师工作的桌面工作台。

---

## 项目目标

帮助工程师完成以下工作：

* 管理今天需要完成的任务
* 记录开发过程中的临时笔记
* 查询历史开发记录
* 积累个人知识库
* 提供工程开发过程中最常用的小工具（后续版本）
