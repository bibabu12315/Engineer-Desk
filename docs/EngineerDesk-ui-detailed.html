▲ 单栏默认视图（保存状态、⛶、置顶钉三处细节见 §3 交互）

1.1 标题栏（36px）

  • ◀ ▶ 历史导航：跳到相邻有记录的日期；无相邻记录时按钮置灰（rgba 0.4）。
  • 标题：无框 QLineEdit，占位「标题」，加粗 13px，输入即触发自动保存。
  • 日期胶囊：格式 MM-DD 周X，等宽数字（tabular-nums），切日期自动刷新。
  • 🔍 搜索：弹搜索对话框（§6）；📅 日历：弹日历（§7）。
  • 📌 置顶钉：钉住 = 红色 📌；未钉 = 灰色 📍；状态持久化。
  • ⚙ 设置：弹设置对话框（§8）；×：隐藏到托盘（不是退出），hover 红底。

1.2 格式工具栏（28px，按钮靠右，Word 式零记忆负担）

  • B / I / S / U：加粗、斜体、删除线、下划线，作用于选区。
  • 🖍 高亮：下弹 6 色色板（黄 #FFF176 / 绿 #A5D6A7 / 蓝 #90CAF9 / 粉 #F48FB1 / 橙 #FFB74D / 紫 #CE93D8）+「无填充」；菜单弹出瞬间快照选区，防止菜单抢焦点丢选区。
  • ☑ 待办行：当前行三态循环 ☐ → ☑ → 普通行。
  • ⎺ 分割线：插入 12 个 ─（品牌橙 #FF9F0A、居中、另起段）；刻意不用 <hr>，因 QTextEdit 导出 HTML 时 hr 后内容会丢失。
  • ⬌ 分区开关：单栏 / 左右分区切换，激活态橙底（全应用唯二用强调色的按钮之一）；状态按天记忆。

1.3 编辑器行为（StickyEditor）

  • 存储自适应：有格式存 HTML，纯文本存纯文本（兼容旧数据）。
  • 粘贴强制去格式：只接受纯文本，丢弃外来富文本。
  • 分割线划块：两条分割线之间的内容是一个「块」；光标在块内时右键菜单追加「归档到项目 ▾」，复制块文本（带 MM-DD 日期前缀）到项目备注或子项备注，原文保留。
  • 标签自动提取：保存时从纯文本抓取 #Tag，显示在编辑器下方标签栏，点击标签直接打开搜索。

2. 主窗口 · 左右分区模式 ⬌ 手动切换

左 = 记录（可归档），右 = 自由草稿区（不参与归档）；默认比例 60 : 40，可拖分割条；各自独立自动保存与搜索。

3. 底部工具栏 · 项目胶囊条 26px + 30px

3.1 底部工具栏（左导航 / 右状态）

  • ＜ 回到今天 ＞：文字链式按钮，与标题栏 ◀▶ 同逻辑但更轻。
  • ⏩ 顺延未完成：把当前日期所有未完成 Todo 复制到下一自然日，状态栏提示「已顺延 N 项」。
  • ⛶ 居中按钮：一键把窗口移回主屏中央——兜底「外接屏拔掉后窗口找不到」；程序还监听 screenRemoved 自动回收，跨屏时按 DPR 补偿保持物理尺寸不变。
  • 保存状态：绿色「✓ 已保存」（2 秒淡出）、「已顺延 N 项」（3 秒）、「✓ 已归档到『XX』（原文保留）」。

3.2 项目胶囊条

  • 每颗胶囊 = 图标 名称 完成/总数，按最近活跃时间排序；超过 6 个横向滚动，无硬上限。
  • 三态配色：常规灰 / 全完成绿底 / ≥7 天未碰橙底并追加「· N天没碰」。
  • 左键点胶囊在正下方弹项目弹窗（§5），再点同胶囊收起；右键弹删除菜单（确认后级联删除子项）。
  • + 项目：虚线 ghost 胶囊，点开主题化输入弹层，可从 12 个常用 emoji 图标中选择，也可在名称前直接输入 emoji；回车创建，Esc / 点外部收起不创建。

9. 系统层行为 托盘 / 窗口管理

  • 系统托盘：左键点图标显示窗口；菜单含「显示 / 移到主屏中央 / 设置 / 退出」。关窗 ≠ 退出（× 只隐藏到托盘），真正退出走托盘菜单。
  • 自动保存：编辑防抖触发，切日期 / 隐藏 / 关闭 / 拖拽缩放结束均强制落库；标题栏、正文、草稿、Todo、标签、窗口位置尺寸全量保存。
  • 多屏健壮性：启动与拔屏后检查窗口是否在任何屏幕可视区内，不在则静默移回主屏中央（不弹出、不打断托盘隐藏状态）；跨屏按 DPR 比值补偿尺寸，物理大小不变。
  • 深浅色：启动读系统 ColorScheme，系统切换即时刷新 chrome；便签底色在下次加载便签时生效。
