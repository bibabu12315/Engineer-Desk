02面板形态：浮动属性卡

与 Excalidraw 原生属性面板同语言：浮在画布上、不参与布局流。顶栏「∿ 波形」按钮仍是唯一入口，点击开合（快捷键 W）。

项规格
位置画布视口左上角，top:64px; left:16px（避开顶栏 island）；固定，不随画布平移缩放
尺寸宽 236px 固定；高度随内容自适应（族切换时平滑过渡 160ms）
视觉令牌白底 #FFFFFF · 描边 #E6E6EA · 圆角 12px · 投影 0 2px 4px rgba(0,0,0,.05), 0 8px 24px rgba(0,0,0,.08) —— 与 Excalidraw island 完全一致
显隐「∿ 波形」点击切换 / W / Esc 关闭；出现动画：从左侧 8px 滑入 + fade，180ms ease-out
激活态面板开着时，顶栏「∿ 波形」按钮保持高亮（同 Excalidraw 选中工具态）；画布交互完全不受影响
折叠态参数面板关闭后参数保留在内存 + 场景属性中，重开原样恢复
为什么不用左列：Excalidraw 的画布是全屏自由空间，属性面板悬浮其上。左列会挤压画布、重排已有内容，且视觉上多了一层"窗口套窗口"。浮动卡是 Excalidraw、tldraw、Figma 共同的设计语言，用户零学习成本。

03信息架构：波形族 + 族内参数

结构（三层）
  • 波形族：顶部 2-tab 分段控件——PWM / 三角波。后续新增波形（正弦、梯形、自定义逐段…）即新增一个 tab。
  • 族参数：仅渲染当前族的字段，字段由族的 schema 声明（数字步进器 / 选项段 / 文本）。
  • 放置：面板底部无按钮——参数区本身就是"待发状态"，放置由画布交互完成（见 §4）。
扩展机制：每个族 = 一个注册项 { id, 标签名, schema[], generate(params, bbox) }。WavePanel 读注册表自动渲染 tab 与字段，加波形不动面板代码。

04放置交互：点一下就落，拖一下定大小

对齐 Excalidraw 画矩形的心智模型：面板只管参数，画布只管位置和大小。不再有"插入到画布"按钮。

状态触发画布表现光标
S1 待发面板开启且族已选无变化crosshair 十字（进入画布区域后）
S2 拖拽中画布 pointerdown 并移动ghost 预览：按当前族参数在拖出的包围盒内实时绘制半透明虚线波形 + 宽/高尺寸标注；水平拖 = 宽度（决定周期宽），垂直拖 = 幅度（覆盖面板"幅值/格"），参数驱动的通道数、周期数不变十字
S3 提交pointerupghost 转正：注入原生 Excalidraw 元素（波形折线 + 通道名 + 标注虚线），整组自动选中，可直接拖动/缩放/改色默认
单击放置pointerdown → up 位移 < 4px按默认尺寸放置：周期宽 20px × 默认幅值，锚点 = 点击点左上—
取消拖拽中 Esc 或右键ghost 消失，回到 S1，已调参数保留—

拖拽语义（映射规则）：拖出的包围盒 = 波形的"物理画幅"。周期宽 = 盒宽 ÷ N；线幅 = 盒高。面板中的"占空比/计数模式/互补"等形状参数在拖拽中不变，只有"大小类"参数（幅值）被垂直拖动覆盖。Shift 拖 = 锁定默认比例（只改位置不改大小？否——只等比放大）。

05细节与边界

场景行为
面板开着时切换工具（如选中 ▢）面板保持但暂停"待发态"（光标恢复默认）；点回空白处（无元素）且当前工具为选择工具时恢复待发。避免误落波形。
参数修改时画布已有 ghost不支持——ghost 仅存在于拖拽过程中，参数修改只能发生在 S1
画布缩放/平移中拖拽拖拽启动即锁定视口，拖拽期间滚轮平移忽略；ghost 坐标全部用视口坐标系
拖得太小（<40×24px）视为误触，回落为"默认尺寸单击放置"，避免生成不可编辑的迷你波形
重复放置提交后面板保持开启、参数保留，可连续点画多组（S3 → S1 无感循环）
Undo整组一次 updateScene 注入，Ctrl+Z 一次撤一组
参数随场景保存（已拍板 Q1）组的每个 line 元素携带 customData: { waveFamily, params, bbox }；双击组内任一元素 → 面板打开并还原该组参数，改参后原位重生成（替换旧组，位置=原 bbox）
面板遮挡画布内容浮动卡可拖拽标题栏移动位置（记忆到 localStorage）；默认位置放左上角空白概率最高

06实现要点（交接）

sketch-app/src/
├── WavePanel.tsx        # 浮动卡：族tabs + schema 渲染 + 待发状态机（S1-S3）
├── wavegen/
│   ├── registry.ts      # 族注册表 { id, label, schema, generate(params,bbox) }
│   ├── pwm.ts           # 单路 / 互补+死区（同一族内选项）
│   └── triangle.ts      # 向上 / 中央对齐 / 向下
└── usePlaceTool.ts      # pointerdown/move/up + ghost overlay + Esc/右键取消
  • ghost 不进 scene：拖拽中的预览画在独立 SVG overlay（绝对定位在画布容器上），pointerup 才 updateScene 注入真元素——不污染 undo 栈。
  • 坐标系：ghost 用视口 px；提交时经 getViewportCoords() 换算为场景坐标，再按包围盒映射周期宽/幅值。
  • 双击编辑：命中 customData.waveFamily 的元素组 → 面板开 + 参数回填 + 重生成替换。这是 Q1（参数随场景保存）的交互闭环。
  • 待发光标：给画布容器加 cursor:crosshair 类，仅当面板开启且无选中元素时生效。
验收标准（V2.1-b 更新版）
  • 点「∿ 波形」→ 左上浮出属性卡，画布布局零变化；再点/W/Esc 收起。
  • PWM / 三角波 tab 切换，字段只显示当前族的；互补关 → 死区行消失。
  • 画布单击 → 默认尺寸落图；按住拖拽 → 虚线 ghost 跟手 + 宽高标注 → 松手转正并整组选中。
  • 拖拽中 Esc 取消无残留；连续放置 ≥ 3 组参数不丢。
  • 双击已生成波形组 → 面板回填参数 → 改占空比重生成 → 旧组被原位替换。
