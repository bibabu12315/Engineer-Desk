# Engineer Desk

一款面向工程师的 **PySide6 桌面便签工作台**：日常记录、待办、项目管理与工程小工具的本地一体化入口。所有数据存本地 SQLite，不依赖任何云服务。

## 功能

### 便签与记录
- **富文本便签**：加粗 / 斜体 / 删除线 / 下划线 / 荧光笔高亮 / 待办行（☐↔☑）/ 分割线
- **粘贴截图**：剪贴板图片直接 Ctrl+V 内嵌进笔记（base64 随笔记存储，无需图片文件夹）
- **链接自动识别**：粘贴或输入的网址自动变为可点击链接，Ctrl+单击 在浏览器打开
- **分块归档**：分割线划分内容块，右键可将整块归档到对应项目
- **双面板**：左侧正文（可归档）+ 右侧自由草稿区
- **自动保存**：内容变更即存 SQLite，历史记录可回溯

### 待办与项目管理
- Todo 列表（自绘复选框）、标签栏、项目胶囊条
- 日历 / 历史记录 / 全局搜索 / 设置（含深色主题、开机启动、系统托盘）

### Engineer Sketch · 草图画板（内嵌 Excalidraw）
- 便签格式栏 ✏️ 打开，系统浏览器全功能手绘白板（完全本地运行）
- **波形生成器**：PWM（单路 / 互补 + 死区，红色虚线标注死区边沿）与三角波（向上 / 中央对齐 / 向下），单击放置、拖拽定大小，双击波形可回填参数原位重生成
- 波形以参数元数据持久化，可二次编辑

## 运行

```bash
pip install -r requirements.txt
python main.py
```

依赖：Python 3.10+，PySide6 ≥ 6.5。

## 打包

```bash
build.bat        # PyInstaller 打包（含草图板静态资源）
```

## 目录结构
