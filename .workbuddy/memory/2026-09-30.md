# 2026-09-30

## Engineer Desk 便签工具两项改动

### 1. 数据目录迁移到工程内 data/（历史数据保全）

- 新增 `src/utils/paths.py`：统一解析工程根、数据目录、数据库路径。
  - 默认数据目录 = `<工程根>/data/`，可用环境变量 `ENGINEERDESK_DATA_DIR` 覆盖。
  - 打包（PyInstaller）运行时从 exe 所在目录向上最多 4 级查找含 `src/`+`main.py` 的目录作为工程根，
    因此即使 `build.bat` 清空 `dist/`，数据仍指向工程根的 `data/`。
- `src/database/db_manager.py`：
  - 数据库路径改由 `paths.get_database_path()` 提供（原先写死在 `%APPDATA%/EngineerDesk/`）。
  - 新增 `_migrate_legacy_data()`：目标库不存在/为空时，用 SQLite 在线备份接口
    `src.backup(dst)` 从 `%APPDATA%\EngineerDesk\engineer_desk.db` 复制（能带上未落盘的 WAL 数据）。
    只执行一次，不覆盖已有数据，旧库保留。
  - 移除不再使用的 `import os`。
- 新增 `data/README.md`，说明目录用途、迁移规则、备份方式。
- 已验证：迁移后 53 条便签 / 183 条 Todo / 1 个标签 / 2 条配置完整。

### 2. 便签一键移动到主屏幕中央（双屏场景）

- `src/ui/main_window.py` 新增：
  - `center_on_primary_screen(reveal=True)`：按 `primaryScreen().availableGeometry()` 居中并保存位置。
  - `_ensure_on_screen()`：窗口不在任何屏幕可视区域时移回主屏（启动兜底 + 屏幕移除时调用）。
  - `_on_screen_removed()`：监听 `QApplication.screenRemoved`，300ms 后延迟检查（拔外接屏自动救回）。
  - 底部工具栏右侧新增 `⛶` 按钮（tooltip「移动到主屏幕中央」），位置在 addStretch 之后、保存状态之前。
  - 按钮连接必须用 `lambda:`，因为 PySide6 的 `clicked` 会带 bool 参数，否则 reveal 会被传成 False。
- `src/ui/system_tray.py`：`SystemTray.__init__` 增加可选 `center_callback`，右键菜单新增「移动到主屏幕中央」。
- `main.py`：创建托盘时传入 `center_callback`。

### 测试方式

`StickyNoteWindow` + `SystemTray`，验证居中坐标、越界救回、托盘菜单项。
